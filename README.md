# EECS 280 Projects

My solutions to the programming projects for EECS 280 (Programming and Introductory Data Structures) at the University of Michigan, written in C++.

## Projects

| Folder | Description |
|--------|-------------|
| `eecs280_cli_lab` | Command-line and development environment lab |
| `p1-stats` | Statistical computations on data using C++ functions |
| `p2-image-processing` | Image processing, including content-aware resizing |
| `p3-euchre` | Simulation of the Euchre card game with AI and human players |
| `p4-ml-classifier` | Machine learning text classifier |
| `p5-list-editor` | Templated linked list and a text editor built on it |
| `p6-bst-map` | Binary search tree and a map container built on it |

## Build and Run

Each project folder has its own Makefile.

```bash
cd p3-euchre
make
```

## Tools

C++, Make, g++, Valgrind
